# Chrome Extensions

個人用 Chrome 拡張機能のコレクションです。

## 拡張機能一覧

### [Auto Dark Mode](./auto-dark-mode/)
ダークモード未対応のページを CSS filter で自動的にダーク化します。
- OS のダークモード設定に連動して自動ON/OFF
- フィルター強度の調整
- サイトごとの除外設定

### [Tab Auto Closer](./tab-auto-closer/)
一定時間非アクティブなタブを自動的に閉じます。
- 非アクティブ時間の閾値を設定可能
- ピン留めタブは対象外
- フォーカス中ウィンドウのアクティブタブは保護

## インストール方法

1. このリポジトリを ZIP でダウンロード、または `git clone` する
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. インストールしたい拡張機能のフォルダ（例: `auto-dark-mode`）を選択する

各拡張機能は独立しており、必要なものだけ個別に読み込めます。
